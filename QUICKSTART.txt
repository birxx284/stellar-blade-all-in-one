STELLAR BLADE - ALL IN ONE 0.7.0
WINDOWS 64-BIT / PORTABLE

Extract the ZIP and run StellarBlade-AllInOne.exe.
You can keep the folder on a USB drive. No installation is required.

1. OPEN YOUR SAVE
Use Open .sav, Paste path, or Find latest.
The usual Steam main save is:
%LOCALAPPDATA%\SB\Saved\SaveGames\<SteamID64>\StellarBladeSave00.sav
Do not select StellarBladeSetting.sav.
Compatible GVAS and EVAS v1 with a valid CRC32 are supported.
An opening report explains missing files, unsupported structures, or invalid CRC32.

2. PREPARE EDITS
Gold is available directly in the main window.
Consumables and items opens a separate, searchable item window.
Outfits and collections opens a separate cosmetic and collection window.
Select a row to read how to get it, where it is found, and its NG+/DLC requirements.
The 304-entry guide works without a save too. Search also matches guide details.
Angel / Fusion guide: Prepare required item adds Symbol of Legacy. Save a copy,
then equip the earrings and enter an already-unlocked Tachy Mode in game.
Permanent Angel is a separate external mod replacing Red Passion. Its guide links
to the author; preparing Red Passion does not install that mod.
Special references and uncatalogued owned identifiers cannot be added as fake suits.
The full offline acquisition guide is in docs/COSMETIC-GUIDE.md.
Player upgrades and Emil's shop edits HP/Beta core levels, unspent SP and Stellar Tears.
HP/Beta: choose the target upgrade level. If cores are missing, either lower the
level or enable Grant missing cores. This grants and spends only missing credits;
it does not mark bodies in the world as collected. MAX means the game limit.
Burst: choose expansion gear, then Inventory only or an unlocked gear slot.
Inventory only requires you to equip the item in game before capacity increases.
Choosing a slot replaces its gear; the old gear stays in inventory.
NG+ equipment and cores adds exospines, gear and missing core/material stacks.
Choose an item and level, or use All Mk2 equipment / All supported equipment.
Chill NG+ preset prepares all 89 Mk2 entries, exospines level 3, HP/Beta 9,
weapon 40, at least 999 SP, gold and supplies. It does not save immediately.
Material stock is granted before upgrade costs. Weapon upgrades cost 1 core per
level; HP/Beta upgrades cost 3 matching cores per level. Exact quantity edits
override minimum stock. New equipment must be equipped in game.
Existing equipped exospines receive matching upgraded levels without changing IDs.
The preset requires an existing NG+ save. Source chests and bodies remain
collectible: blocking those pickups is not implemented because the exact
item-to-world links could not be verified. See docs/NGPLUS-GUIDE.txt for details.
Closing an auxiliary window keeps the selection. All edits are saved together.
Prepared edits do not modify the original file.

3. SAVE COPY
Click Save copy with the game closed. The button is enabled after loading a valid save.
The current gold, selected item and player fields are collected and validated
automatically. Prepare and Review changes are optional.
You can also save an unchanged copy. Cancelling the destination writes nothing.
A new modified .sav and a permanent original backup are created.
If a destination already exists, another name is used. Nothing is overwritten.

BACKUPS
The complete original is copied to CopiasSeguridad beside the destination.
The backup is verified and accompanied by a dated recovery note and SHA-256.
Previous backups are never removed automatically.
To restore: close the game, keep a copy of current progress, and copy the original
backup to an appropriate slot in your own save folder.

LIMITS
Physical chests, quests, story completion and Emil purchases are not changed.
NieR collection edits require existing NieR data. DLC licenses are not activated.
Only recognized, existing item stacks can have their quantities changed. A missing
Stellar Tear stack can be recreated only with existing NieR data and a currency template.
HP/Beta numeric maximum stats are calculated by the game from upgrade levels and gear.
Burst capacity changes through expansion gear. Tachy capacity and skill/story unlocks
are not changed. Going above supported HP/Beta limits needs a game-data mod.
Weapon power is editable up to level 15 normal / 40 NG+. Core costs are applied.
Exospine upgrades are explicitly granted without module costs; source chests,
story abilities, quests, learned skills and the difficulty setting stay unchanged.
Separate equipped charges are kept on increases and clamped on reductions.
Other EVAS versions and damaged integrity checks are rejected.

IN-GAME CONTROLS
The separate in-game window includes money, health, energies and one consumable.
It requires manual calibration in every session. No automatic profile is provided.
Read its Help tab, recalibrate after loading another area or save, and verify each
candidate using a small change. F8 stops value holding; it does not undo edits.

VALIDATION
An end user reported 0.3.3 working on their PC. The new guide, player window and save
operations have automated checks; new features still need in-game testing. This does not guarantee every game build.
Verify loading, inventory, saving and reloading with your modified copy.

The program works offline and never uploads your save.
