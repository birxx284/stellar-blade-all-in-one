The wardrobe catalog derives internal identifiers, categories, DLC labels and
English display names from that project's data/catalog.json. Acquisition areas,
location facts and requirements are also derived from its structured metadata.
Our concise English instructions are newly written summaries; third-party guide
paragraphs and images are not reproduced. The original Apache-2.0 attribution
and license are retained. Sources are linked per entry.

Changes include a C# port, a preserving writer, bounded parsing, inventory and
collection operations, editable existing quantity records, a combined Windows
interface, session memory controls, persistent original backups and structural tests.

Research sample (not distributed):
https://github.com/lecher-wang/Stellar-Blade-100-completion-save-file
It was used to inspect schemas and test byte-identical round trips. Neither the
original save nor its account identifier is included in this package.

Functional item identifiers are used to address existing save records. The
BetaCrystal/Gold name is corroborated by the original author's mod description:
https://www.nexusmods.com/stellarblade/mods/788
No code or assets from that mod are included.

No source or binaries from Stellar Blade Mod Suite, Stellar Blade Cheat Manager,
CNSSaveConverter or stellar-blade-macos-save-editor are incorporated. The Nexus
Mod Suite page is linked only as an independent, optional reference.

The EVAS v1 envelope layout (8-byte prefix and a little-endian CRC32 of bytes
from offset 8 to before the final 4-byte checksum) was researched against:
https://github.com/lotress/CNSSaveConverter/blob/master/savefile.py
https://github.com/wuxiao00j/stellar-blade-macos-save-editor/blob/main/Sources/TrainerCore/SaveParser.swift
Our CRC32 and envelope implementation is independently written; code from those
projects is not included. Tests use the standard CRC32 vector and a Python zlib
checksum as independent reference values. Game compatibility remains unverified.

Player-upgrade research (format facts and identifiers only; no assets bundled):
https://github.com/Stellar-Blade-Modding-Team/Stellar-Blade-Modding-Guide
The public v1.4.1 type mappings identify ESBCharacterLevelType: None=0, Body=1,
Beta=2, RechargeablePotion=3, Weapon=4, GearSlot=5, ProtectorSlot=6.
The research save stores seven UInt32Property entries in PlayerActor.LevelArray.
Core item identifiers BodyCore and BetaCore and Stellar Tear alias Money_Nier
were cross-checked against public item metadata. No third-party catalog or code
from the Control Panel is incorporated or redistributed.
https://www.nexusmods.com/stellarblade/mods/1911 (Money_Nier = Emil shop currency)
https://www.viiozero.de/leitfaeden/stellar-blade/ (author's collection walkthrough:
three Body/Beta cores per upgrade; six base-game upgrades)
https://www.nexusmods.com/stellarblade/mods/1061 (existing extended core limits,
load-time automatic core consumption, and CharacterLevelTable dependency)
Burst/Tachy maxima are not inferred from current gauge values.

Burst expansion functionality is independently written. Four functional item
identifiers (Gear_MaxBurstGauge_Uncommon/Rare and their _MK2 variants) were
cross-checked with actual inventory records in the public research save. Only
identifier/name facts are used; no third-party item catalog is redistributed.
ESBEquipType GearCommon1..4 map to saved equipment keys 1..4 in the public type
mapping; LevelArray[5] is the GearSlot upgrade count. Only existing unlocked
slot records are replaced. Current gauge values are not treated as capacities.

NG+ equipment and weapon expansion (independent implementation):
https://blog.playstation.com/?p=391256
Shift Up documents weapon caps 15 normal / 40 NG+, HP/Beta caps 6/9 and Mk2 gear.
All 178 supported equipment identifiers were cross-checked against actual records
in the non-distributed research save. Gear rarity/Mk2 IDs are not synthesized from
unknown variants. Common Burst Expansion Gear is excluded as unverified.
PT_ exospines use StatLevel 1..3; gear uses StatLevel 1. Equipment slots are copies
of the same SavedGuid inventory instance. Weapon is LevelArray[4], corroborated
by ESBCharacterLevelType in the public type mapping and the research save.
No third-party equipment catalog, descriptions, source, mod or game assets are
incorporated. Labels summarize functional identifiers and item-name facts.
